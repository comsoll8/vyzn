Backfill Genres re-fetches genre tags for movies/shows that were already matched before genre shelves existed — it doesn't touch titles, posters or anything else.

Automatic scanning

"When files change" watches your Movies/TV folders and scans a couple of minutes after the last new file appears, so downloads finish first. It doesn't spin up idle disks, but some network shares don't report changes — use "Once a day" there. Removed files aren't detected yet.

Connections

These override whatever's set in docker-compose.yml, and take effect immediately — no restart needed. A friend setting up their own VYZN can leave docker-compose.yml untouched and configure everything from here.

Remote Access (Tailscale)

Installs VYZN onto your private Tailscale network so you can reach it from outside your home, with no port-forwarding. Get an auth key from the Tailscale admin console, paste it below, and connect.
