VYZN — Privacy Policy

Last updated: 2 October 2026

VYZN is a self-hosted media server app. The Android TV app in this repository is a thin client: it connects to a VYZN server that you (or someone you know) run on your own hardware, and nothing else.

What this app does not do

The VYZN Android TV app does not collect, transmit, store, or share any personal data, usage analytics, advertising identifiers, or crash reports with us, with Google, or with any third party. There is no account system, no telemetry, and no network connection made to any server other than the one address you enter when you first set up the app.

What the app does with your data

All data the app works with — your media library, playback progress, profiles, watchlist, and any settings (such as TMDB or Seerr API keys) — is sent only to the VYZN server address you configure, and is stored only on that server's own hardware, under your control. We (the developer) have no access to it.

Third-party services your server may contact

Depending on how the server you connect to is configured, it may itself reach out to third-party services on your behalf, such as TMDB (for movie/show metadata and artwork) or a self-hosted Overseerr/Jellyseerr instance (for request management). Those requests originate from your server, not from this Android TV app directly, and are governed by those services' own privacy policies.

Permissions

The app requests network access (to reach your VYZN server) and, where applicable, storage/notification permissions standard to Android TV apps for playback. None of these are used to collect data about you.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a new "Last updated" date.

Contact

Questions about this policy can be raised via the project's GitHub repository.
